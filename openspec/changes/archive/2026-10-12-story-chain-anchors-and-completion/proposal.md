# 提案：补齐 1872—1893 历史锚点，并把剧情链完成度接进结局

## 为什么 / Why

两笔欠账，都来自 `#4` 的原始描述，实测依据取自 `#11` 打通的模拟底盘：

| 事实 | 实测 |
|---|---|
| 1872—1882 有链吗 | **零条**。原 14 条链的锚点是 1851/1853/1856/1861/1862/1865/1871/1883/…，**11 年完全空白** |
| 1884—1893 有链吗 | **零条**。1883（中法）与 1894（甲午）之间 **10 年空白**，而这段恰是"中兴如何转为崩局"的关键十年 |
| 除这两段还有洞吗 | 有：1895—1897、1902—1903、**1905—1910**（后者是辛亥的正面铺陈，最大的一处） |
| 名望接进结局了，链完成度呢 | 没接。`save.completedChainIds` 从存档 v2 就存在，但**只有事件下发在读它**，结局页与判定都不看 |
| 玩家实际能走多远 | 开链模拟：200 局**全部恰好在第 22 回合撞线**，终局年份只到 **1865**，23 条链完成 5 条 |

最后一条是本提案的**约束条件**：剧本连发挤占普通事件，导致游戏在 1865 就结束了。
所以「补 1872 年以后的锚点」单独做**不会让玩家读到这些内容** —— 已被模拟证实
（14→23 条链之后，开链基线的 22.0 / range=[22,22] / 1865 一个数都没变）。
密度闸门是另一件事，见下方"未做"。

## 关键决策与被排除的方案

| 决策 | 理由 |
|---|---|
| 完成度**只做展示，不进胜利判定** | 三条路径里选了最保守的一条。做成 gate 的直接后果：「关链」的模拟 `chainsCompleted` 恒为 0，胜率一步归零，86.0% 基线整条作废；更根本的是逻辑反向 —— 链是**奖励**（节点 effects 远大于兜底事件），用"吃了多少奖励"当胜利条件只会逼人拖着不完成链。真要治速通，工具是链的密度闸门 |
| 完成度分母用「终局年份前可达链数」而不是 23 | 剧本按年代解锁，1865 年通关的人碰不到 1894 的链。用 23 当分母等于**惩罚通关太快**，而同一份经历在 1912 的存档上会算出完全不同的等级——那是口径错误不是难度 |
| 可达链数 < 3 时**不给称号** | 1/1=100% 这种"满级"毫无信息量，只会把开局没几回合的存档吹成完人 |
| **不给任何既有链补前置** | 给已上线的链加前置会改变它的触发时机（原本到年份就触发，改后须等前置跑完），那是行为变更而不是补内容。新增的 5 组前置只挂在新链上 |
| 1884「新疆建省」做成**扩节点**而不是新链 | 既有的「收复伊犁」节点文案里**已经写着**"新疆建省"、选项 a 就叫"筹边建省安民"。另开一条会同题读两遍。做法是先收紧原节点（改为只讲改约），再把建省续成第 4 节 |
| 新链 `min-yong-gong-shang` 与 `yang-wu-yun-dong` 靠"军用/民用"分工 | 两条链第二节年代相邻（江南制造局 vs 轮船招商局），不显式区分就会让人觉得同一主题读两遍 |
| 链镜像与模拟镜像都**由脚本从服务端生成**，不手抄 | 23 条链 67 节点手抄必错，而"抄错"正是守卫要防的事。#11 里试过近似数值，量出开链胜率 0%（真值是 100%），方向完全相反 |
| 顺手把三处**硬编码链数**的测试改成从服务端取真值 | `story-chains-meta.test.ts` 写死 14、`copywriting.test.ts` 写死 14，一补链就红。这不是断言有效，是维护税；改成 `SERVER_CHAINS.length` 派生 |
| 新选项必须过「无严格占优」检测，历史债**记录不修** | 8 处新写的占优选项全部补上"只有被压制项才有的收益"（如「缓议建省以节经费」补 `silver:+200`，让"省经费"真的成为一条独立理由）。但 `liu-qiu-tai-wan/node-1` 的既有占优**不动** —— 那是已上线数值，改它属于平衡变更，要单独标定，不该夹在补内容里 |

## 风险与验证

- **补链会加重挤占吗**：不会更坏但也没治好。实测 22 回合定局**一个数都没变**（新锚点全在 1865 之后，游戏到不了）。
  这既是"内容补齐安全"的证据，也是"密度闸门必须单独做"的证据。
- **前端镜像漏同步的后果**：`CHAIN_META` 不同步 → 结局页算不出可达链数、事件卡显示英文 chainId；
  由 `mirror-consistency.test.ts`（含 `startYear`）与 `sim-chain-mirror.test.ts` 两道守卫兜住。
- **旧存档兼容**：`completedChainIds` 缺字段时按空数组处理（`?? []`），`getChainCompletion(null)` 返回全零。
